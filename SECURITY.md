# Security

Report a vulnerability in `vsx-diff` privately through [GitHub Security Advisories](https://github.com/bymustfa/vsx-diff/security/advisories/new).

Please do not open a public GitHub issue, pull request, or discussion for a suspected vulnerability. A private advisory lets the maintainer look at the report, confirm it, and ship a fix before the details are public.

Include the `vsx-diff` version, the command you ran, and enough detail to reproduce the problem. If the report is about an extension package rather than this tool, say which registry and versions you compared, and avoid pasting live credentials or exploit payloads.

Security issues in third-party extensions that `vsx-diff` merely diffs are outside this project's advisory process. Report those to the extension publisher and the registry that served the package.
